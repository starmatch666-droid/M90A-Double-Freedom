# M90A + 双重自由联动

## M90A 光环霰弹枪

- 保留 M90A 自己的弹丸类型，**没有**替换成双重自由的弹丸
- 每发弹丸数：11 → 12
- 单弹丸普通伤害：55 → 70
- 单弹丸耐久伤害：20 → 35
- 穿甲：轻甲 AP2 → 中甲 AP3
- 保留原有外观、弹道、枪械机构、弹匣、装填和其他操作方式

## DBS-2 双重自由

- 改为单手武器，可与弹道盾等单手装备配合
- 保留自身原生弹丸
- 每颗弹丸追加游戏原生 `Fire` 状态，强度 2
- 伤害、耐久伤害、穿甲、弹丸数、弹容量和装填保持原版

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。

无需其他前置，下载即用。

## 安装

导入本包到 Arsenal / HD2 Mod Manager，启用后部署，彻底退出游戏再重新启动。Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 适配游戏构建 **25327279**。
- 运行时受保护写入与回读已通过，用户已实测确认生效。
- 单手持枪动画、搬运任务物品时的表现、实际燃烧触发仍建议自行复核。

## 日志

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\M90ADoubleFreedom.log
```

写入成功会记录 `applied_template_gameplay_unverified`；数据不匹配时记录 `*_not_write` 并**拒绝写入**，不会强行覆盖。

## 注意

- 内存模组属**客户端运行时改动**：只在本次游戏会话内生效，退出游戏即恢复原状。
- 联机表现可能与队友不一致，并存在**反作弊风险**。建议仅在知情固定队环境中使用。
- 卸载：用管理器禁用本包并重新部署；手动安装需保持 `patch_N` 编号连续，**不要直接删除中间编号的文件**。
